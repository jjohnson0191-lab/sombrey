# Sombrey Owner Dashboard (apps/owner)

The private, owner/business-only Sombrey dashboard.

## Phase 1 status

Boundary marker only — no project scaffolding yet.

## Scope (approved specification, not yet implemented)

Users, subscriptions, revenue/MRR, retention/churn, band orders, device
fleet information, app usage, marketing analytics, pixels/attribution,
support operations, readiness/system monitoring.

## Not part of this app

Customer-facing functionality of any kind — that lives in
`apps/mobile`. This app is not accessible to customers.

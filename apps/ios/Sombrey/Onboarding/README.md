# Onboarding

`BandPairingView.swift` — the first-launch, pre-authentication band
pairing scene added in the Phase 3 training-architecture expansion.
Optional; never blocks reaching sign-in. Uses the existing Studio
Instrument environment/motion/typography system verbatim, per that
phase's explicit instruction not to introduce a separate visual
language.

No other onboarding surface exists yet (profile setup, goal-setting
wizard, etc.) — those remain a later phase.

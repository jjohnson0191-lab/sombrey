# Sombrey Website (apps/website)

The new public, commercial Sombrey website.

## Phase 1 status

Boundary marker only — no project scaffolding yet.

## Scope (approved specification, not yet implemented)

Brand, marketing, product information, physical band sales/checkout,
pricing, FAQ, legal, support content, SEO, marketing analytics/pixels.

## Explicitly out of scope

**No customer/subscriber login. No customer dashboard.** Customer
authentication, workouts, nutrition, wearable data, and subscription
management live in `apps/mobile`, never here.
